# Model source

"Asaro Head" by AgentSCAD — https://www.thingiverse.com/thing:7287701
Licensed under Creative Commons Attribution-ShareAlike (CC BY-SA).
A fan recreation of John Asaro's Planes of the Head.

These are the original 3D-print STL files, unmodified. `npm run convert:asaro`
reassembles them (front + back halves, both ears) into
`public/models/asaro.glb`, which is a derivative work under the same
license. The printing base (`Asaro-Base.stl`) isn't used.
